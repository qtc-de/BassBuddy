### Project layout

---

```
pitch-wasm/            Rust crate: pitch-detection algorithms (yin.rs, acf.rs, hps.rs)
src/pitch-wasm/         Compiled wasm output (generated by npm run build:wasm)
public/exercises/       Built-in exercise YAML files (subfolders OK) + generated manifest.json
scripts/generate-exercise-manifest.mjs  Recursively scans public/exercises, writes manifest.json
src/lib/notes.js        Frequency <-> note <-> fret math
src/lib/algorithms.js   Algorithm metadata shown in the UI
src/lib/exercises.js    Exercise YAML parsing/validation, built-in + localStorage-persisted upload loading
src/lib/synth.js        Web Audio synthesis for "play what you hear" exercise playback
src/composables/usePitchDetector.js  Mic capture + wasm pitch detection
src/composables/useExercises.js      Exercise selection, import, scoring state machine
src/composables/useSettings.js       Persisted user settings (e.g. show note names)
src/components/Fretboard.vue         Fretboard display
src/App.vue             Top-level UI: controls, note readout, tuner meter, exercise panel
```
